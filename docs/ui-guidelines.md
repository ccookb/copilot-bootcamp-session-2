# UI Guidelines

These guidelines define the baseline UI rules for frontend work in this repository.

## Material Components

- Use Material components for all new UI elements and layouts.
- Prefer standard Material patterns for navigation, forms, dialogs, cards, and data display.
- Avoid custom components when a Material component already covers the use case.

## Color Palette

Use the following palette consistently across the app:

- Primary: `#1976D2`
- Primary Dark: `#115293`
- Secondary: `#9C27B0`
- Success: `#2E7D32`
- Warning: `#ED6C02`
- Error: `#D32F2F`
- Background: `#F5F7FA`
- Surface: `#FFFFFF`
- Text Primary: `#1F2937`
- Text Secondary: `#6B7280`

## Button Styles

- Use Material button components for all actions.
- Primary actions: `contained` button with the Primary color.
- Secondary actions: `outlined` button with the Primary color.
- Tertiary or low-emphasis actions: `text` button.
- Keep button corner radius consistent at `8px`.
- Minimum button height: `40px`.
- Use sentence case for button labels (for example: `Save changes`).
